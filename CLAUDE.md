# Gradebook

App de escritorio (Tauri 2 + React + TS) para que el profesor gestione grupos, evaluaciones, entregas por GitHub y PDFs de notas.

- Al terminar cualquier feature, cambio de comportamiento o fix, invoca la skill `semver-bump` para subir la version y anotar el CHANGELOG.
- Nombres de personas: siempre primero nombres y luego apellidos.
- Interfaz en espanol; codigo sin acentos.
